# 📊 Grade Calculator

**Java Console-Based Student Grade Evaluation System**

> Calculate total marks, average percentage, and academic grade instantly.

---

## 📖 Overview

Grade Calculator is a **console-based Java application** designed to calculate a student's academic performance based on marks entered for multiple subjects.

The program computes:

- Total marks obtained
- Average percentage
- Final grade classification

This project demonstrates essential Java programming concepts such as user input handling, arrays, loops, conditional statements, and method implementation.

## 🚀 Quick Start

### Compile the program

```bash
javac Gradecalculator.java
```

### Run the program

```bash

```

## ⚙️ Features

- 📥 Accepts marks for multiple subjects
- ➕ Calculates total marks
- 📈 Computes average percentage
- 🏆 Assigns grade automatically
- ☕ Beginner-friendly Java implementation
- ⚡ Fast console execution

---

## 📝 How It Works

### **[ INPUT SUBJECT COUNT ]**

Enter the total number of subjects.

### **[ ENTER MARKS ]**

Input marks for each subject (out of 100).

### **[ CALCULATION ]**

The system calculates:

- Total Marks
- Average Percentage

### **[ GRADE EVALUATION ]**

Grades are assigned based on average percentage.

## 📊 Grade Classification

| Percentage Range | Grade |
|-----------------|-------|
| 90 and above | A+ |
| 80 – 89 | A |
| 70 – 79 | B |
| 60 – 69 | C |
| 50 – 59 | D |
| Below 50 | F |
